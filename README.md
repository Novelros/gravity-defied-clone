# Gravity Defied — браузерный клон
<img width="800" height="450" alt="loop" src="https://github.com/user-attachments/assets/2d29d590-4b48-4935-b628-53316d622abc" />


Ремейк классической мобильной игры Gravity Defied на чистом JavaScript и Canvas, без библиотек и сборки.

Задача — довезти мотоциклиста до финиша как можно быстрее и не ударить его головой о землю.

**Играть онлайн:** https://novelros.github.io/gravity-defied-clone/

## Возможности

- 13 трасс в трёх лигах: Новичок, Любитель, Профи
- три мотоцикла (100cc, 175cc, 220cc), новый открывается после прохождения лиги
- рекорды и «призрак» лучшего заезда, сохраняются в браузере
- редактор трасс: рампы, ящики, шипы, пропасти, тоннели, петли
- управление с клавиатуры и экранный джойстик на телефоне

## Управление

| Клавиши | Действие |
| --- | --- |
| `W` / `↑` | газ |
| `S` / `↓` | тормоз |
| `A` / `←` | наклон назад |
| `D` / `→` | наклон вперёд |
| `R` | заново |
| `Esc` / `P` | пауза |

## Запуск

Игра использует ES-модули, поэтому `index.html` нужно открывать через локальный сервер, а не двойным щелчком:

```bash
npx serve .
# или
python -m http.server
```

После этого откройте в браузере адрес, который покажет сервер.
